# Project Overview

The current method of monitoring the status of VMs has been manually, one at a time. Automation was important to increase efficiency and save time.

# Features

I implemented automatic dating of the report, obtaining of VM data, evaluation and displaying of VM health, and a summary of the VM numbers in regards to their totals as well as how many are healthy or in need of attention.  

# Commands Used

I used Write-Host, Get-AzVM, Select-Object, and Where-Object, primarily. 

# Lessons Learned

I learned that it can become really, really difficult to keep track of things if you do not go into it with a plan. I got lost in the middle of everything at one point, and it was a pain. If I hadn't done the buildup with LM7, it would have been even worse.
