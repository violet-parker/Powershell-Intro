## New Command I Discovered
Command:
Get-SqlSmartAdmin
## What it Does
The command gets the SQL Smart Admin object, and uses the name parameter to get smart admin object properties. 
## One Example From Help 
PS C:\> Get-SqlSmartAdmin -Name "Computer\MyInstance"
